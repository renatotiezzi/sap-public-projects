# 03.1_LAST_VERSION

A versão atual de cada objeto: **a fonte da verdade** da demanda.

- Toda correção é aplicada primeiro aqui (correção mínima, sem refactor fora do escopo).
- Ordem para achar a versão atual de um objeto: `03.1_LAST_VERSION/` → `02_CODIGO/` → `03_OBJETOS_ORIGINAIS/`.
- Após a aprovação, o objeto corrigido substitui a versão anterior aqui e, quando aplicável, vai para `02_CODIGO/`.
- O baseline continua intocado em `03_OBJETOS_ORIGINAIS/`.
